## Key Decisions

### Caching Strategy (hand-written rationale)

| Asset Type | Strategy | Reason |
|---|---|---|
| App shell (JS, CSS, HTML) | **Precache** (cache-first) | These files are versioned by Vite hash. They never change for a given deploy. Cache-first gives instant load. |
| Images (avatars, course covers) | **CacheFirst** with size limit | Images are large and rarely change. Cache-first avoids repeated downloads. |
| Google Fonts CSS | **StaleWhileRevalidate** | Fonts rarely change but we want to eventually pick up updates. |
| Supabase API calls | **NetworkFirst** with 3s timeout | User data must be fresh. Fall back to cache only when offline so habits still show. |

### Offline Banner
- Listens to `window.addEventListener('online'/'offline')`
- Shows a fixed bottom banner: "You're offline — changes will sync when reconnected"
- Hides on reconnect. No third-party library.

### Offline Queue
- When `navigator.onLine === false` at the time of handleAdd, push the habit to `localStorage` key `offline_habit_queue`
- On reconnect (online event), flush the queue: call createHabit for each entry, then clear queue
- Pending habits shown with a "⏳ Queued" badge in the habit list

### registerType: "prompt"
- The service worker does NOT auto-update. It waits.
- UpdateToast renders "New version available — Refresh" banner
- On click, calls `updateServiceWorker(true)` which skips waiting and reloads

### Share Button
- `navigator.share()` if available (mobile)
- Falls back to `navigator.clipboard.writeText(window.location.href)` with a "Copied!" tooltip on desktop

### Mobile-first fixes
- Stats grid: `grid grid-cols-1 sm:grid-cols-3` (already 3 cols — shrink to 1 on mobile)
- Habit card: ensure no fixed widths that cause overflow
- Avatar + Add Habit button row: wrap on very small screens
- All container max-widths have `px-4` padding
- Habits header: `flex-col sm:flex-row` on mobile

## vite.config.ts PWA config
```ts
VitePWA({
  registerType: 'prompt',
  includeAssets: ['logo.png', 'icons/*.png'],
  manifest: false, // use our public/manifest.json
  workbox: {
    globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}'],
    runtimeCaching: [
      {
        urlPattern: ({ url }) => url.origin === 'https://fonts.googleapis.com',
        handler: 'StaleWhileRevalidate',
        options: { cacheName: 'google-fonts-stylesheets' }
      },
      {
        urlPattern: ({ url }) => url.origin === 'https://fonts.gstatic.com',
        handler: 'CacheFirst',
        options: {
          cacheName: 'google-fonts-webfonts',
          expiration: { maxEntries: 30, maxAgeSeconds: 60 * 60 * 24 * 365 }
        }
      },
      {
        urlPattern: ({ url }) => url.hostname.includes('supabase.co'),
        handler: 'NetworkFirst',
        options: {
          cacheName: 'supabase-api',
          networkTimeoutSeconds: 3,
          expiration: { maxEntries: 50, maxAgeSeconds: 60 * 5 }
        }
      },
      {
        urlPattern: /\.(?:png|jpg|jpeg|svg|gif|webp)$/,
        handler: 'CacheFirst',
        options: {
          cacheName: 'images',
          expiration: { maxEntries: 60, maxAgeSeconds: 60 * 60 * 24 * 30 }
        }
      }
    ]
  }
})
```
